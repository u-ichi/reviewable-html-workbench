# 文書ヘッダーのパンくずリスト

文書モデルの `metadata.breadcrumbs` に上位ページを上から順に渡すと、文書ヘッダーにパンくずリストを表示します。現在の文書名は `title` から末尾へ追加します。未指定または空配列の場合は表示せず、単独文書の従来表示を維持します。

```json
{
  "title": "CLINIAL内のCRC",
  "metadata": {
    "breadcrumbs": [
      {"label": "全体像", "href": "../index.html"},
      {"label": "ペルソナ", "href": "../personas/index.html"}
    ]
  }
}
```

親子関係の判定、ページの存在確認、公開先に応じたURLの決定は呼出元が担当します。RHWは渡された順序で表示し、ファイルの階層や特定リポジトリの構成を推測しません。
リンクは相対URLまたはHTTP(S)を指定します。表示名とURLはHTMLへ埋め込む際にエスケープし、スクリプトを実行するURLなどは検査と描画で拒否します。

パンくずは文書のヘッダー内に最初からHTMLとして描画され、現在ページは `aria-current="page"` で示します。短い画面幅では折り返します。レビュー表示・公開表示・`publish` の出力で共通の表示を使います。

## 確認

`tests/test_breadcrumbs.py` は、文書ヘッダーへの表示、公開後の保持、任意項目としての互換性、表示名のエスケープ、不正なリンクの拒否を確認します。
ブラウザでは親リンクへの移動、キーボード操作、狭い画面での折り返し、初期描画を確認します。
